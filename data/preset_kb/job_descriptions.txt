# 岗位 JD 与面试流程

## Java 后端开发工程师（初级/应届）

岗位职责：参与公司核心业务系统的后端开发，负责模块设计、编码与单元测试；与产品、前端协作完成需求落地；参与系统性能优化和技术方案评审。任职要求：本科及以上学历，计算机相关专业；熟悉 Java 基础（集合、多线程、IO），了解 Spring Boot 框架；熟悉 MySQL 和 Redis，了解基本 SQL 优化；熟悉 Git 和 Linux 常用命令；有良好的代码规范和团队协作意识。加分项：有个人技术博客或 GitHub 开源项目；了解消息队列或微服务。

## Java 后端开发工程师（高级 / 资深）

岗位职责：负责核心系统的架构设计与技术选型，主导技术方案评审；解决线上疑难问题，性能优化，保障系统稳定性和高可用；指导初中级工程师，推动团队技术进步。任职要求：5 年以上 Java 开发经验，2 年以上架构设计经验；精通 Spring 全家桶、MyBatis 原理，读过关键源码；精通 MySQL 性能优化（慢 SQL、索引、分库分表）；有大规模分布式系统经验（微服务、消息队列、缓存、分布式事务）；熟悉 Docker/K8s 容器化部署。技术深度之外，看重系统设计思维和解决问题的工程能力。

## 全栈工程师岗位

岗位职责：独立负责产品功能的前后端全栈开发，从需求到上线的全链路负责；参与技术选型，搭建前后端开发框架；持续优化用户体验和系统性能。任职要求：3 年以上全栈或后端开发经验；熟悉一种后端语言（Java/Python/Go/Node.js），有完整的后端 API 开发经验；熟悉一种前端框架（Vue/React），能独立完成前端页面开发；熟悉数据库设计和 SQL 优化；了解 CI/CD 流程和自动化部署。加分项：有 AI 产品开发经验，使用过 LLM API 或 RAG 技术栈。全栈工程师需要更广的技术面，但也要在一两个方向上有深度。

## 高级前端开发工程师

岗位职责：负责前端架构设计和核心模块开发，包括组件库建设和工程化提升；与后端协作优化 API 设计，提升用户体验；推动前端性能优化和代码质量提升。任职要求：3 年以上前端开发经验；精通 HTML5/CSS3/JavaScript/TypeScript，深入理解浏览器渲染原理和网络协议；精通 Vue 或 React 框架，理解其响应式原理和虚拟 DOM 机制；有前端工程化经验（Webpack/Vite 配置、CI/CD）；有性能优化实际经验（首屏加载、懒加载、缓存策略、构建优化）。加分项：了解 Node.js 或全栈能力，有 SSR 或微前端经验。

## 数据工程师岗位

岗位职责：设计和维护数据 Pipeline，完成数据采集、清洗、转换和加载；搭建数据仓库，支撑业务分析和 BI 报表；优化数据任务性能，保障数据质量和时效性。任职要求：熟悉 SQL 和数据建模（星型、雪花型）；熟悉大数据生态（Hadoop/Spark/Flink/Hive）至少一种；有 ETL 开发经验，了解数据质量监控方法；有 Python 脚本能力，能处理数据清洗和自动化任务。加分项：了解实时计算和流式处理，有数据治理或数据湖建设经验。数据工程师是业务和数据之间的桥梁，统计思维和工程能力同等重要。

## 技术面试流程与评价维度

技术面试通常包含：1) 自我介绍（1~2 分钟，简述经历和能力侧重点）；2) 项目深挖（面试官针对简历上的项目提问，考验项目真实性和技术深度）；3) 基础知识（编程语言、数据库、网络、操作系统等核心概念）；4) 算法与数据结构（手写代码，考察逻辑思维和代码规范性）；5) 系统设计（高级岗位考察架构设计能力，如"设计一个秒杀系统"）；6) 反问环节（候选人向面试官提问，展示对公司和岗位的兴趣）。评价维度：技术深度（对应聘级别的基础和原理理解）、项目经验（实际做过什么和解决过什么难题）、学习能力（新技术接受速度、问题排查思路）、沟通协作（能否清晰表达技术方案）。面试是双向选择，候选人也应主动了解团队技术栈和业务方向。

## 如何在简历中突出技术亮点

好的技术简历应遵循以下原则：1) 一页为佳，重点突出，不要凑字数；2) 每个项目经历采用 STAR 原则（Situation 背景、Task 任务、Action 行动、Result 结果），结果尽量量化（"将接口耗时从 300ms 降到 50ms"、"QPS 提升 5 倍"）；3) 技术栈写在显眼位置，但不要只列名词，要结合项目说明应用场景；4) 突出个人贡献而非团队成就（"我负责设计并实现了 XX 模块"）；5) 开源项目、技术博客、Stack Overflow 贡献是加分项；6) 简历不要造假，面试深挖几个问题就能戳穿。一个优秀的简历应该是"你有我没有、你强我更强"的差异化展示，而不是千篇一律的技术栈列表。
