## 5. 明确不做 / 挂账

**长期不做：**
- **不拆多 Agent**：工具未到互相干扰的量级（判据见 `docs/Agent工具设计.md` §五）。**LangGraph 已于 v4.0 引入**——但仅用于「一键求职准备」的长流程编排（`services/agent_v2/`），pin `>=0.2,<0.3`；v1 ReAct 轨继续走 langchain 0.3 线，**默认装 1.x 会把 langchain-core 升到 1.6.3 打断 v1**
- 不做支付 / 配额计费 / 多租户后台
- 不做移动端 App、不做国际化
- 不为"技术新颖"替换已稳定的栈（pgvector / Ollama / Vue3 均保留）
- docx / 图片简历与 OCR：不做（简历只收文本型 PDF 的边界维持）

**挂账（触发条件出现时再做）：**
- 防爆破 Redis 集中计数 + 显式 CORS 配置：仅在升级多 worker 部署或跨域部署时启用（#19，当前单 worker + 同源架构下无害）
- 云服务器线上部署：owner 有服务器资源后，从 v3.8 的本地演示模式自然升级（prod compose 与部署文档在 7.5/8.2 已备好）

## 6. 执行纪律

1. **一次只推一个批次**：v3.7 全部收口 → 再开 v3.8；单方向耗时超预估 1.5 倍 → 砍范围（沿用 PROJECT-PLAN §8）
2. 改提示词 → 递增 `PROMPT_VERSION` + 用 `test-resumes/` 5 份跑回归
3. 改切块 / embedding / 检索 → 必跑 `scripts/eval_rag.py` 对比基线（hit@1 87.8% / hit@5 100%）
4. 增删工具 / 改工具描述 → 必跑 `scripts/eval_agent_routing.py` 对比基线（40/40）
5. 改模型结构 → 必走 Alembic 迁移
6. **跑全量 pytest 前先确认三容器在**（先跑 `python -m scripts.check_env --skip-ai`）；跑完记得 `python -m scripts.seed_kb_preset` 恢复语料——**7.4 测试隔离改造完成后本条"恢复语料"部分作废**
7. **7.3 之后装/升任何依赖必须同步 `requirements.lock`**；7.6 之后每批收口以"push + CI 全绿"为完成标志
8. 启动项目前先跑 `python -m scripts.check_env` 自检（容器闲置会假死）
