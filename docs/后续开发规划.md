## 5. 明确不做

- **不拆多 Agent / 不引 LangGraph**：工具未到互相干扰的量级；真要引 langgraph 必须锁 `>=0.3,<0.4`（默认装 1.x 会把 langchain-core 升到 1.6.3，打断现有 Agent 层）
- 不做支付 / 配额计费 / 多租户后台
- 不做移动端 App、不做国际化
- 不为"技术新颖"替换已稳定的栈（pgvector / Ollama / Vue3 均保留）

## 6. 执行纪律

1. **一次只推一个方向**，做完再开下一个
2. 改提示词 → 递增 `PROMPT_VERSION` + 用 `test-resumes/` 5 份跑回归
3. 改切块 / embedding / 检索 → 必跑 `scripts/eval_rag.py` 对比基线
4. 增删工具 / 改工具描述 → 必跑 `scripts/eval_agent_routing.py` 对比基线
5. 改模型结构 → 必走 Alembic 迁移
6. **跑全量 pytest 前先确认三容器在**（否则请求会挂起）；跑完记得 `python -m scripts.seed_kb_preset` 恢复语料
7. 单方向耗时超预估 1.5 倍 → 砍范围（沿用 PROJECT-PLAN §8）
