4

RAG 混合检索（核心）

双路召回 + RRF 融合；本版本主要提优点

切块入库

段落合并 ~600 字/块 + 60 字重叠 · 超长硬切不丢内容 · 幂等重试 · 向量维度护栏

向量路

pgvector HNSW 余弦距离 · nomic-embed-text 768 维 · 排序交给数据库命中索引

词法路

jieba lcut_for_search 分词 + 停用词表 + 手写 Okapi BM25（不引第三方 BM25 库）

RRF 融合

k=5 · 每路候选 50 · 只比名次不比原始分数，免去余弦与 BM25 的量纲归一化

输出与引用

top-k 带来源标题 / 块序号 / 相似度；前端折叠展示；未命中时明确告知而非编造

混合路径不套用相似度阈值 ——「仅词法命中、向量分低」正是要救回的术语类查询（如「聚簇索引」「类的加载过程」），BM25 自带 IDF 已抑噪 评测基线（49 题）：hit@1 71.4% → 87.8%，hit@5 91.8% → 100%，翻转明细显示无任何一题变差 纯向量路径仍按 kb_min_similarity 0.65 过滤（实测相关 0.70+ / 无关 0.60-）；kb_hybrid_enabled=False 可一键回退做 A/B

个人数据工具一律按归属者过滤，识别不到身份时明确拒绝，而不是返回空数据让模型脑补 工具内 LLM 单独计量：走 _run_tool_llm，受 daily_agent_tool_llm_limit=20 约束、记 agent_tool_llm 用量，与主循环 daily_agent_limit=30 分开 暂不拆多 Agent：工具未到会互相干扰的量级，拆分会给每次提问加一层纯路由开销；判据与触发信号记在 docs/Agent工具设计.md
