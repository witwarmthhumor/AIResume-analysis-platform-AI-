一、版本说明
================================================================================
v3.2 合并以下需求，统一施工：

1. 管理面板 → 数据看板改名（侧边栏菜单项 + 页面标题）
2. 五统计卡片重设计：五卡一行等宽，参考 Right Code 卡片风格

三、分页设计汇总
================================================================================
+-------------+-------------+---------+----------+----------------------+
| 表格        | 分页方式    | 每页条数| 总页数   | 备注                 |
+-------------+-------------+---------+----------+----------------------+
| 用户列表    | 前端 slice  | 10 条   | 7 页     | 63 条，切页滚回顶部  |
| 近 7 日用量 | 前端 slice  | 5 条    | 2 页     | 7 条，柱状图全量显示 |
+-------------+-------------+---------+----------+----------------------+

为什么用前端分页：
  - 当前用户 63 条、用量 7 条，全量返回无性能压力
  - 零后端改动，符合 v3.2 纯前端定位
  - 未来用户量破千时再改后端分页接口（加 page/page_size 参数）

分页组件统一规范：
  - 左侧文字：共 N 条 · 第 X/Y 页
  - 右侧控件：上一页 | 页码（含省略号…）| 下一页
  - 当前页青绿背景白字粗体
  - 禁用态灰底灰字 cursor:not-allowed
  - 页码超过 5 页时用省略号折叠（1 2 3 … 7）

八、风险点与注意事项
================================================================================
1. 分页页码折叠：用户列表 7 页，页码显示 1 2 3 … 7，点击省略号不跳转；
   实现时用简单的页码数组生成，不做复杂的窗口滑动。
2. 用量柱状图全量显示：左侧表格分页只影响表格，柱状图始终用全部 7 条
   数据渲染，不要误用分页后的数据。
3. AdminPanel 根容器宽度覆盖：App.vue 的 .page 是 max-width 960px，
   AdminPanel 需要在根元素上加 style="max-width:1100px;margin:0 auto;"
   或用 scoped 样式覆盖。注意 scoped 样式无法直接改父级 .page，需要
   在 AdminPanel 根容器上设宽度并 margin:0 auto，让内容区撑满。
4. 表头 sticky：在 overflow-y auto 的容器内，thead position:sticky;top:0
   需要 thead 背景不透明（#fff），否则滚动时内容会透过表头。
5. 悬浮效果用 CSS transition，不用 JS，性能更好；五卡用 scoped 样式
   .stat-card:hover 实现。
6. 分页切换时表格滚动回顶部：给表格容器加 ref，翻页方法里
   nextTick(() => { tableRef.value.scrollTop = 0 })。
