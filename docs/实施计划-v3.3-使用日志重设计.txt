二、关键决策点（已确认）
================================================================================
决策1：内容方案
  方案A（采用）：真正的使用日志——显示 usage_logs 明细（动作/模型/Token/IP/时间）
  方案B（弃用）：仅改名换皮——内容仍是简历/分析/面试分组
  理由：项目已有 usage_logs 表，字段正好对应图二的模型/Token/IP；
        做成真正的使用日志更符合命名和参考效果。原 /api/history 接口保留不删。

决策2：日期选择器实现
  方案A（采用）：自定义 Vue 组件 DateRangePicker.vue（日历浮层+时间输入）
  方案B（弃用）：原生 <input type="date"> + 文本时间
  理由：原生 date 样式不可控，且不支持范围+时间组合；自定义组件可完全
        匹配图二效果（月份切换、上下月灰色、选中圆、开始/结束时间）。
        不引入第三方日期库，纯手写约 200 行。

决策3：分页方式
  后端分页（采用）：usage_logs 可能随使用增长，后端分页更稳妥；
  接口返回 {items, total, page, page_size}，前端翻页重新请求。

3.2 后端新增接口
--------------------------------------------------------------------------------
文件：backend/app/api/usage.py（新增）
路由：GET /api/usage/logs
权限：get_current_user（需登录，只查当前用户的日志）

请求参数（query，全部可选）：
  - page: int = 1（页码，从1开始）
  - page_size: int = 10（每页条数，最大50）
  - action_type: str（动作类型，精确匹配：
    parse / analysis / interview_message / kb_upload / playground）
  - model_name: str（模型名，模糊匹配 ILIKE）
  - ip_address: str（IP，精确匹配）
  - start_date: str（开始日期，格式 YYYY-MM-DD，含当天 00:00:00）
  - end_date: str（结束日期，格式 YYYY-MM-DD，含当天 23:59:59）

查询逻辑：
  - base: UsageLog.user_id == current_user.id
  - 各筛选条件 and 叠加
  - 日期范围：created_at >= start_date 00:00:00 AND created_at <= end_date 23:59:59
  - 排序：created_at DESC, id DESC
  - 分页：offset=(page-1)*page_size, limit=page_size
  - total：同条件 count(*)

返回结构：
  {
    "items": [
      {
        "id": 1,
        "action_type": "analysis",
        "model_name": "qwen-plus",
        "tokens_total": 2450,
        "ip_address": "127.0.0.1",
        "created_at": "2026-09-03T21:06:00"
      }
    ],
    "total": 5,
    "page": 1,
    "page_size": 10
  }

路由注册：在 app/main.py 的 RouterRegistry 或路由汇总处注册 usage router
（按项目现有路由注册机制，参考其他 api 模块的注册方式）。

测试：backend/tests/test_usage.py（新增）
  - 未登录返回 401
  - 登录后只返回自己的日志（不能看到其他用户的）
  - 分页正确（page/page_size/total）
  - 各筛选条件生效（action_type/model_name/ip/日期范围）
  - 空结果返回 items=[] total=0

3.3 前端新增组件：DateRangePicker.vue
--------------------------------------------------------------------------------
文件：frontend/src/components/DateRangePicker.vue（新增）
用途：日期范围选择器，点击输入框/日历图标弹出浮层，选择日期范围+时间段。

Props：
  - modelValue: Object { start: string (YYYY-MM-DD), end: string,
                          startTime: "HH:mm", endTime: "HH:mm" }
  - placeholder: string（默认 "选择日期范围"）

Emits：
  - update:modelValue（确定时触发）

组件结构：
  <template>
    <div class="drp-wrapper">
      <!-- 输入框（只读展示，点击弹出浮层） -->
      <div class="drp-input" @click="showPicker = !showPicker">
        <span>📅</span>
        <span>{{ displayText }}</span>
        <span>📆</span>
      </div>
      <!-- 浮层（v-if showPicker，绝对定位） -->
      <div class="drp-popup" v-if="showPicker">
        <!-- 月份切换 -->
        <div class="drp-header">
          <button @click="prevMonth">‹</button>
          <span>{{ currentYear }}年{{ currentMonth }}月</span>
          <button @click="nextMonth">›</button>
        </div>
        <!-- 星期表头 -->
        <div class="drp-weekdays">一二三四五六日</div>
        <!-- 日期网格 -->
        <div class="drp-days">
          <span v-for="day in days" :class="day.class" @click="selectDay(day)">
            {{ day.date }}
          </span>
        </div>
        <!-- 时间选择 -->
        <div class="drp-times">
          <label>开始 <input type="time" v-model="startTime" /></label>
          <label>结束 <input type="time" v-model="endTime" /></label>
        </div>
        <!-- 操作按钮 -->
        <div class="drp-actions">
          <button @click="cancel">取消</button>
          <button @click="confirm">确定</button>
        </div>
      </div>
    </div>
  </template>

核心逻辑：
  - currentYear/currentMonth：当前显示的年月，默认今天
  - days：计算 6x7=42 个格子，包含上月末/本月/下月初
    - 上月末/下月初：灰色（class="other-month"）
    - 本月正常日：可点击
    - 选中开始日：青绿圆白字
    - 选中结束日：青绿圆白字（如果范围选择）
    - 范围内日期：浅绿背景（class="in-range"）
  - selectDay：点击日期
    - 如果没有选中开始日，设为开始日
    - 如果已有开始日但没有结束日，设为结束日（如果早于开始日则交换）
    - 如果已有完整范围，重置为新的开始日
    - 单日选择：开始日=结束日（点击同一个日期两次或直接确定）
  - prevMonth/nextMonth：切换月份，跨年处理
  - confirm：emit update:modelValue，关闭浮层
  - cancel：恢复原值，关闭浮层
  - 点击浮层外部关闭：监听 document click，判断 target 是否在组件内

样式（scoped）：
  - .drp-wrapper: position: relative
  - .drp-input: 边框圆角，focus 时青绿边框+阴影，cursor: pointer
  - .drp-popup: position: absolute, top: 100%+6px, left: 0, z-index: 100,

  - 范围内：background rgba(16,185,129,0.1)
  - 其他月：color #D1D5DB
  - 时间输入：border 1px #E5E7EB, border-radius 6px, padding 4px 6px
  - 确定按钮：青绿背景白字；取消按钮：白底灰字

3.4 前端 HistoryView.vue 重写

Script：
  import { ref, computed, onMounted } from 'vue'
  import { get } from '../api.js'
  import DateRangePicker from './DateRangePicker.vue'

  // 数据
  const logs = ref([])           // 当前页日志列表
  const total = ref(0)           // 总条数
  const loading = ref(false)
  const error = ref('')

  // 分页
  const page = ref(1)
  const pageSize = ref(10)       // 每页条数（10/20/50）
  const totalPages = computed(() => Math.max(1, Math.ceil(total.value / pageSize.value)))

  // 筛选条件
  const dateRange = ref({ start: '', end: '', startTime: '00:00', endTime: '23:59' })
  const actionType = ref('')     // ''=全部
  const modelName = ref('')
  const ipAddress = ref('')

  // 激活筛选数（用于徽章）
  const activeFilters = computed(() => {
    let n = 0
    if (dateRange.value.start) n++
    if (actionType.value) n++
    if (modelName.value) n++
    if (ipAddress.value) n++
    return n
  })

  // 加载日志
  async function loadLogs() {
    loading.value = true
    error.value = ''
    try {
      const params = new URLSearchParams()
      params.set('page', page.value)
      params.set('page_size', pageSize.value)
      if (actionType.value) params.set('action_type', actionType.value)
      if (modelName.value) params.set('model_name', modelName.value)
      if (ipAddress.value) params.set('ip_address', ipAddress.value)
      if (dateRange.value.start) params.set('start_date', dateRange.value.start)
      if (dateRange.value.end) params.set('end_date', dateRange.value.end)
      const res = await get('/api/usage/logs?' + params.toString())
      logs.value = res.items
      total.value = res.total
    } catch (e) {
      error.value = e.message || '加载失败'
    } finally {
      loading.value = false
    }
  }

  // 搜索（带筛选，重置到第1页）
  function search() {
    page.value = 1
    loadLogs()
  }

  // 重置筛选
  function reset() {
    dateRange.value = { start: '', end: '', startTime: '00:00', endTime: '23:59' }
    actionType.value = ''
    modelName.value = ''
    ipAddress.value = ''
    page.value = 1
    loadLogs()
  }

  // 快捷日期（今日/7天/30天）
  function setQuickRange(days) {
    const end = new Date()
    const start = new Date()
    if (days === 1) { /* 今日 */ }
    else { start.setDate(start.getDate() - (days - 1)) }
    dateRange.value = {
      start: formatDate(start), end: formatDate(end),
      startTime: '00:00', endTime: '23:59'
    }
    search()
  }

  // 翻页
  function goPage(p) {
    if (p < 1 || p > totalPages.value) return
    page.value = p
    loadLogs()
  }

  // 改变每页条数
  function onPageSizeChange() {
    page.value = 1
    loadLogs()
  }

  // 动作类型中文映射 + 配色
  const actionMap = {
    parse: { label: '简历解析', color: '#6B7280', bg: '#F3F4F6' },
    analysis: { label: 'AI分析', color: '#1D4ED8', bg: '#DBEAFE' },
    interview_message: { label: '模拟面试', color: '#92400E', bg: '#FEF3C7' },
    kb_upload: { label: '知识库上传', color: '#0E7490', bg: '#CFFAFE' },
    playground: { label: '知识库问答', color: '#065F46', bg: '#D1FAE5' }
  }

  onMounted(loadLogs)

八、风险点与注意事项
================================================================================
1. DateRangePicker 浮层定位：使用 position: absolute + z-index: 100，
   父级 .drp-wrapper 需 position: relative。浮层可能超出卡片边界，
   需确保卡片没有 overflow: hidden（filter-card 不要设 overflow hidden）。

2. 点击外部关闭浮层：在 onMounted 时 addEventListener('click', handleOutside)，
   onUnmounted 时 removeEventListener。handleOutside 判断 event.target 是否
   在组件根元素内（使用 ref + contains）。注意 Vue 的 <script setup> 中
   用 defineExpose 或直接 ref 根元素。

3. 日期范围选择逻辑：支持单日（开始=结束）和范围（开始<结束）。
   点击日期时：无开始→设开始；有开始无结束→设结束（若早于开始则交换）；
   有完整范围→重置为新开始。UI 上范围内日期浅绿背景，开始/结束日青绿圆。

4. 日期格式化：统一用 YYYY-MM-DD（后端 start_date/end_date 参数），
   显示用 YYYY/M/D。时间用 HH:mm（input type="time" 原生格式）。
   注意后端查询时 start_date 含 00:00:00，end_date 含 23:59:59。

5. usage_logs 表字段确认：需确认 model_name 可能为 null（如 parse 动作
   不调用 AI），tokens_total 可能为 0，ip_address 可能为 null。
   前端显示时用 || '-' 或 || 0 兜底。

6. 动作类型枚举：usage_logs.action_type 的实际值需与后端一致
   （parse/analysis/interview_message/kb_upload/playground），
   前端 actionMap 的 key 必须匹配。施工前先查数据库确认实际值。

7. 路由注册：项目使用 RouterRegistry 或手动 include_router，需按现有
   机制注册 usage 路由。施工前查看 app/main.py 或 api/__init__.py 的
   路由注册方式，保持一致。

8. 分页页码显示：当总页数较多时（>7页），用省略号折叠（1 2 3 ... 10），
   简单实现即可，不做复杂窗口滑动。当前数据量小（5条），1页就够。
