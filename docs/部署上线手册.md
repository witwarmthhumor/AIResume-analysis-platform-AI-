# 云部署上线手册（v4.5 预检版）

> **状态**：编排与镜像已预检通过；**实际部署挂账**——尚无云服务器，拿到机器后按本手册执行即可。
> 预检记录：`docker compose -f docker-compose.prod.yml config` 通过（POSTGRES_PASSWORD / JWT_SECRET_KEY / AI_API_KEY 以占位值验证——生产密码不落配置文件，正确姿势）。

## 1. 前置清单

| 项 | 要求 |
|---|---|
| 服务器 | 2C4G 起步（whisper CPU 转写建议 4C8G），Docker + compose v2 |
| 域名 + TLS | 必须 HTTPS——后端 `validate_prod_settings` 启动断言强制 `jwt_secure_cookie=true`，HTTP 下服务**拒绝启动**（v4.4.1 安全件） |
| AI Key | DeepSeek（或任一 OpenAI 兼容供应商）的 key |
| Embedding | 优先本地 Ollama（镜像含在 compose）；无 GPU 机器可改云端 embedding（settings 三行） |

## 2. 部署步骤

```bash
# 1. 拉代码 + 配置（.env 不入库，在服务器上新建）
git clone <repo> && cd AIResume-analysis-platform-AI-
cp backend/.env.example backend/.env   # 如无 example，按下表逐项填

# 2. 必填环境变量（backend/.env）
#    DATABASE_URL=postgresql+psycopg://<user>:<pass>@db:5432/<db>
#    REDIS_URL=redis://redis:6379/0
#    AI_API_KEY=sk-...            AI_BASE_URL=...  AI_MODEL=deepseek-chat
#    JWT_SECRET_KEY=<随机长串>     APP_ENV=prod     JWT_SECURE_COOKIE=true
#    AUTH_GATE_ENABLED=true       AUTO_PROMOTE_FIRST_USER=false   # 启动断言强制口径
#    ASR_WHISPER_MODEL=small      EMBEDDING_BASE_URL=http://ollama:11434/v1

# 3. 起栈 + 迁移 + 管理员
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml exec backend alembic upgrade head
docker compose -f docker-compose.prod.yml exec backend python -m scripts.seed_admin   # 或 SEED_ADMIN_PASSWORD=<强口令>

# 4. 预置语料（首次）
docker compose -f docker-compose.prod.yml exec backend python -m scripts.seed_kb_preset
```

## 3. 验收冒烟（逐项打勾）

- [ ] `GET /health` → ok；`/health/ready` → database+redis ok
- [ ] 未登录访问 `/api/resumes` → 401（闸门生效）
- [ ] admin 登录 → 上传简历 → 生成分析（真实 AI 调用一轮）
- [ ] 模拟面试走 3 轮 → 结束报告四维评分
- [ ] 录音上传 → 转写完成（whisper 首次加载慢，看 worker 日志）
- [ ] AI 客服提问"什么是 RAG" → SSE 逐字流 + done 带 token 记账

## 4. 升级纪律（v4.4.0 实测教训）

**旧版 langgraph 写下的 interrupt 挂起 checkpoint，新版能读不能续跑**。每次升级镜像前：

```bash
# 1) 清场在途：作废 waiting_approval 审批单 + 进行中面试会话（或通知用户完成）
# 2) 升级后 lifespan 会自动把 planning/running 孤儿 run 置 failed（error 指向重试）
# 3) langgraph_* 表不迁移数据——历史快照只读兼容
```

## 5. 已知运行限制

- **uvicorn 必须 `--workers 1`**：Agent v2 的 SSE 事件总线是进程内实现（README 有注记），多副本部署前先换 Redis Pub/Sub
- whisper CPU 转写 5 分钟音频约 2~4 分钟——已在任务队列异步，可按机器情况切 `ASR_WHISPER_MODEL=base` 快速档
