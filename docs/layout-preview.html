HashMap 的底层原理是什么？
🤖
HashMap 在 JDK 8 中由「数组 + 链表 / 红黑树」构成：元素经 hash 定位到桶，冲突时形成链表，链表长度 ≥ 8 且数组容量 ≥ 64 时树化为红黑树，将最坏查询从 O(n) 降到 O(log n)。负载因子默认 0.75，超过阈值触发扩容（容量翻倍并 rehash）……
