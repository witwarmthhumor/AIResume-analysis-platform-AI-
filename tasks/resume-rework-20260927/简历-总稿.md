### AIResume——AI 简历分析与模拟面试平台（个人全栈项目，可直接用）

**技术栈：** Python、FastAPI、PostgreSQL 16（pgvector）、Redis、SQLAlchemy 2、Celery、Vue 3、LangChain 0.3、LangGraph 0.2、Ollama

**项目简介：** 集成简历上传解析、AI 分析报告、多轮模拟面试与知识库问答的全链路 AI 应用平台。针对 AI 输出不可控、长任务阻塞与个人数据越权三大痛点，以「统一 AI 封装层 + RAG 混合检索 + 多 Agent 编排 + 人机协同审批」为架构主线，全程评测驱动迭代。

- 基于 LangGraph 构建「一键求职准备」多 Agent 工作流（规划 → 简历分析 → 岗位匹配 → 定制出题 → 交付，含坏输出回环重试），高风险动作（创建面试场次）经 interrupt 人机协同审批后才执行，PostgresSaver 支持断点续跑；配套 11 个端到端黄金任务评测基线（正常/无简历/坏输出/审批通过/拒绝/超时/检索降级/限额/越权）全部通过。
- 基于 LangChain 0.3 构建 ReAct Agent，落地 11 个业务工具（知识检索、简历查询、面试历史、岗位匹配、出题、答案点评等），统一归属过滤防止个人数据越权，工具路由评测 33/33 达 100% 准确率。
- 搭建 pgvector 混合检索（向量 + jieba/BM25 词法 + RRF 融合），49 题黄金问答集 top-1 命中率 71.4% → 87.8%（top-5 达 100%）且无一题回退。
- 封装 OpenAI 兼容协议层：JSON 结构化校验 + 失败自动重试，提示词带版本号留档，切换模型仅改 3 行配置；Celery + Redis 将解析/入库等长任务异步化（幂等重试），SSE 流式输出 AI 逐字结果与工具调用过程（单次问答 500+ 分片，中断可恢复）。
- 工程质量：77 项安全审计修复（含 2 项横向越权 P0）、287 个 pytest 用例全绿、服务层覆盖率 89%、CI 全绿；数据库快速失败机制实测停库 5.3s 返回 503（修复前挂起 60s+）。

### 二手智析——基于 RAG 的二手交易平台智能分析系统（个人项目，可直接用）

**技术栈：** Python、FastAPI、bge-m3、BM25 + RRF、RAGAS、Chroma、PostgreSQL、Redis、Vue3、Docker

**项目简介：** AI 驱动的二手交易竞品分析与知识库问答平台，围绕大模型落地的幻觉、成本、稳定性、效果可量化四大难题做工程化治理，285 问标注集 + RAGAS 驱动迭代。

- bge-m3 向量 + BM25 + RRF(k=60) 混合检索，向量相似度二次精排 + 文档级保底重排，285 问评测集 Hit@5 由 0.9825 → **1.0000**、MRR@10 由 0.9186 → **0.9506**、nDCG@10 → **0.8280**。
- 三档防幻觉分流（≥0.65 直出 / 0.4~0.65 片段注入 / <0.4 拒答不调 LLM），答案强制来源标注校验，无谓拒答率 20% → 0。
- L1 进程内 LRU + L2 Redis 两级检索缓存（热点命中 <0.05ms）+ SingleFlight 防击穿，Redis 故障 30s 熔断静默降级；Token 级成本预检/记账/累计熔断，ASGI 滑动窗口三档限流。
